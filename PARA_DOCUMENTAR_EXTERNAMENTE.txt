CLIENTES NO FIREBIRD POSSUEM DADOS EM 3 TABELAS SEPARADAS:

1. TABELA: CLIENTE
   ├─ Contém: Dados básicos (nome, CPF, data nascimento, sexo)
   ├─ Campos: CODIGO, NOMECLIENTE, CPF_CNPJ, DIANASCIMENTO, MESNASCIMENTO, ANONASCIMENTO, SEXO, EMAIL1, ATIVO
   └─ Relacionamento: Chave primária = CODIGO

2. TABELA: CADASTRO_TELEFONE
   ├─ Contém: Telefones do cliente (pode ter vários)
   ├─ Campos: TELEFONEPREFIXO, TELEFONE, OBSERVACAO
   └─ Relacionamento: WHERE TIPO_CADASTRO = 1 AND CODIGO_CADASTRO = [ID_CLIENTE]

3. TABELA: CADASTRO_ENDERECO
   ├─ Contém: Endereços do cliente (pode ter vários)
   ├─ Campos: DESCRICAO, ENDERECO, NUMERO, CEP
   └─ Relacionamento: WHERE TIPO_CADASTRO = 1 AND CODIGO_CADASTRO = [ID_CLIENTE]

================================================================================
CAMPO TIPO_CADASTRO
================================================================================

Este campo indica o tipo de entidade:
- 1 = Cliente
- 2 = Fornecedor  
- 3 = Funcionário

SEMPRE usar TIPO_CADASTRO = 1 para buscar dados de CLIENTES!

-- 1. Buscar dados básicos do cliente
SELECT 
    C.CODIGO,
    C.NOMECLIENTE,
    C.CPF_CNPJ,
    C.DIANASCIMENTO,
    C.MESNASCIMENTO,
    C.ANONASCIMENTO,
    C.SEXO,
    C.EMAIL1
FROM CLIENTE C
WHERE C.CODIGO = 37479;

-- 2. Buscar telefones do cliente
SELECT 
    CT.TELEFONEPREFIXO,
    CT.TELEFONE,
    CT.OBSERVACAO
FROM CADASTRO_TELEFONE CT
WHERE CT.TIPO_CADASTRO = 1
AND CT.CODIGO_CADASTRO = 37479;

-- 3. Buscar endereços do cliente  
SELECT 
    CE.DESCRICAO,
    CE.ENDERECO,
    CE.NUMERO,
    CE.CEP
FROM CADASTRO_ENDERECO CE
